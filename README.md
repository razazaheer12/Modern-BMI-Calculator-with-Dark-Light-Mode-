#  Modern BMI Calculator (with Dark/Light Mode)

[![Live Demo](https://img.shields.io/badge/Live%20Demo-View%20Here-brightgreen)](https://razazaheer12.github.io/modern-bmi-calculator)  

A sleek, modern, and responsive **BMI (Body Mass Index) Calculator** built with pure HTML, CSS, and JavaScript. Features live BMI calculation, an animated gauge, dark/light mode toggle, and a beautiful glassmorphism design. Perfect for health enthusiasts and developers looking for a clean, interactive web app!

## ✨ Features

- **🔄 Live BMI Calculation**: Instantly calculates BMI as you type weight and height.
- **📊 Animated Gauge**: Visual progress bar that fills based on BMI value with color-coded categories.
- **🌙 Dark/Light Mode Toggle**: Switch between themes with a smooth toggle button. Defaults to dark mode on load.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- **🎨 Glassmorphism Design**: Modern UI with backdrop blur, gradients, and floating animations.
- **⚡ No Dependencies**: Pure vanilla JavaScript – no frameworks or libraries required.
- **💾 Local Storage**: Remembers your theme preference across sessions.
- **🚀 Fast & Lightweight**: Minimal code for quick loading.

## 📋 How to Use

1. **Enter Weight**: Input your weight in kilograms (kg).
2. **Enter Height**: Input your height in centimeters (cm).
3. **View Results**: See your BMI value, category, and animated gauge update in real-time.
4. **Toggle Theme**: Click the toggle button in the top-right to switch between dark and light modes.

### BMI Categories:
- 🥗 **Underweight**: BMI < 18.5
- ✅ **Normal Weight**: BMI 18.5–24.9
- ⚠️ **Overweight**: BMI 25–29.9
- 🚨 **Obese**: BMI ≥ 30
